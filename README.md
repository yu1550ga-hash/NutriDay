# NutriDay — Android project (расширенная версия)

Русскоязычный офлайн-счётчик калорий с интерфейсом по мотивам предоставленного скриншота.

## Возможности
- Завтрак, обед, ужин и перекусы; переключение даты
- Подсчёт калорий, белков, жиров и углеводов по граммам
- Суточная цель калорий и индикатор прогресса
- Отдельное отображение BMR (базовый обмен), TDEE (общий расход с учётом активности) и плановой калорийности
- План: снижение веса (дефицит), поддержание, набор (профицит) или пользовательская цель
- Расчёт ориентировочной нормы по полу, возрасту, росту, весу, активности и цели (снижение/поддержание/набор)
- Редактируемая цель калорий
- Встроенная база продуктов и поиск по ней
- Добавление своих продуктов, редактирование и удаление записей
- Избранные продукты
- Рецепты с автоматическим подсчётом КБЖУ по ингредиентам и добавлением в дневник
- Статистика за 7 и 30 дней
- Локальное хранение данных на устройстве; интернет не нужен

## Как собрать APK
1. Установите Android Studio и Android SDK Platform 35.
2. Откройте папку `NutriDay_Android` в Android Studio.
3. Дождитесь синхронизации Gradle.
4. Выберите **Build → Build APK(s)**.
5. APK будет создан в `app/build/outputs/apk/debug/app-debug.apk`.

В среде подготовки отсутствуют Android SDK и Gradle, поэтому здесь доступен обновлённый исходный проект, а не скомпилированный APK.

## Важно
Значения пищевой ценности в базе ориентировочные. Проверяйте данные на упаковке. Расчёт суточной калорийности приблизительный и не заменяет рекомендации врача или диетолога. Профиль и дневник хранятся локально на телефоне.


## Обновление v4: главная панель энергии и веса
- Главный экран показывает BMR, TDEE и плановую цель в отдельных карточках с диаграммами-прогресс-барами.
- Пользователь задаёт собственный коридор калорий (например, 1300–1400 ккал); плановая цель рассчитывается как середина коридора.
- Отдельно показывается прогресс потребления относительно нижней и верхней границы коридора.
- Добавлен ручной журнал замеров веса с датой и заметкой, графиком изменения веса, разницей от первого замера и удалением ошибочных записей.
- Последний сохранённый замер веса обновляет вес профиля, чтобы последующие оценки BMR/TDEE использовали актуальные данные.
